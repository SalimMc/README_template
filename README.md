# README_template

This repository aims to give the tools and the templates to build better READMEs so that all your projects will be completly stylized!!! ✪ ω ✪

> [!IMPORTANT]
> The templates in the `/templates` directory have all been extracted from external GitHub repositories and projects created by third-party authors.
>
> The README files and templates are the result of their work. All rights remain reserved by their respective authors.
>
> Each template is distributed under the license of the original repository from which it was sourced. A link to the original repository is provided at the beginning of each document, where you can find the applicable license and attribution information.

## o(*￣▽￣*)o Usage

For the templates present in the `/templates` directory, you can inspire yourself from the designs or use them in allegation to the corresponding licenses of their repositories. 

All the code, the templates, the badges in the `/raw_templates` and `/elements` directories are totally freee to use without any restriction. (⌐■_■)

---

## 🔄 Customization

Make the templates your own by customising it with your repository parameters, informations, add badges, GIFs, pictures, screenshots and paste it into your own README.
